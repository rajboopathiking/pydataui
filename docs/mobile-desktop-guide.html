Compiling Standalone Android APK

PyDataUI automatically configures Gradle, updates Android assets, bridges your local Wi-Fi IP, and outputs app-debug.apk.

1

Install Prerequisites (JDK 17 or 21)

Ensure you have a modern Java Development Kit installed and set as default:

brew install openjdk@21
export JAVA_HOME=$(/usr/libexec/java_home -v 21)
2

Accept Android SDK Licenses

If you encounter "License for package Android SDK Build-Tools not accepted", execute:

export ANDROID_HOME=/usr/local/share/android-commandlinetools
yes | $ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager --licenses
3

Build the Standalone APK

Run the build command from your repository root:

pydataui mobile build --platform android
Output artifacts:
  • ./app-debug.apk (Workspace root)
  • dist/app-debug.apk
  • android/app/build/outputs/apk/debug/app-debug.apk
4

Install to Physical Phone via ADB

Connect your Android phone with USB Debugging enabled:

# Install via PyDataUI CLI:
pydataui mobile install --platform android

# Or directly using adb:
adb install -r app-debug.apk

Compiling & Sideloading iOS IPA

Package your application into app-debug.ipa for sideloading on any iPhone or iPad without needing a $99/year Apple Developer program.

1

Generate the Unsigned IPA Bundle

Execute the iOS build command on your Mac:

pydataui mobile build --platform ios
Output: ./app-debug.ipa (195 KB) and dist/app-debug.ipa.
2

Sideload with Sideloadly or AltStore

Install the IPA onto your physical iOS device:

  1. Download and install Sideloadly (macOS/Windows).
  2. Plug your iPhone into your computer via Lightning/USB-C.
  3. Drag app-debug.ipa into Sideloadly.
  4. Enter your standard free Apple ID and click Start.
  5. On your phone, go to Settings ➡️ Privacy & Security ➡️ Developer Mode and turn it ON.
  6. Under Settings ➡️ General ➡️ VPN & Device Management, tap your Apple ID and select Trust.

In-Browser Mobile Device Simulator

Test mobile layouts instantly without touching native compilers:

pydataui mobile preview app.py

Key Simulator Features:

  • Device Chassis: iPhone 15 Pro, Google Pixel 8, iPad Mini.
  • Orientation: Instant toggle between Portrait and Landscape.
  • Live QR Code: Scan with your camera to open the live app on real hardware over Wi-Fi.
  • Hot Reloading: Edits in Python instantly update the phone frame.

Desktop Apps: Native Window & Tauri 2.0

Distribute native desktop applications for macOS, Windows, and Linux.

1. Lightweight Window (0s Setup)

Launches standard OS webview window immediately:

pydataui run app.py --desktop

2. Tauri 2.0 Binary (Production)

Compiles stand-alone sandboxed desktop binary:

pydataui desktop build
